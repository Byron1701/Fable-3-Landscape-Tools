Fable 3 .ghf and .ehf Landscape exporters - with simple gui.

Requires Python and Tkinter.

Single and Batch export to .obj and .pgm.

Fable 3 .ghf files contain the main level landscape/terrain which is navigable by the player.
Fable 3 .ehf files contain filler or surrounding terrain which is not.

Tick Flip Y if you want obj to correspond to game orientation. (Lord only knows why you wouldn't!)
Leave all other settings as they are unless you want to play around with scaling, etc.

Default scaling of exported .obj files should be compatible with landscapes exported by Adarec1994's Fable 2 Asset Browser.
This could be useful in tandem with his level editor.

If anyone spots any issues please let me know.
